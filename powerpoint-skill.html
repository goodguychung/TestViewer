Powerpoint Skill

用 AI 自動建立、編輯、分析 PowerPoint 簡報的強大技能
⭐ 227K★ 🔖 NousResearch 📜 MIT 開源 🐍 python-pptx 🧊 離線執行

🐾 這是什麼？

讓「我」直接用 python-pptx 幫老大建立 / 讀取 / 編輯 PowerPoint (.pptx) 報告與簡報。 有 5 個輔助腳本，全離線執行、不一定要安裝 Microsoft Office。 從「一份 JSON 規格」就能自動生成整份投影片，也能抽文字、改內容、套公司範本、轉成圖片確認。

⚙️ 能幫老大做什麼（功能總覽）

🆕
建立簡報
從 JSON 規格生成 .pptx，含標題、條列、表格、圖表、圖片、備忘稿
🔍
讀取分析
抽文字、備忘稿、表格、圖表資料、內嵌圖片出來看
✏️
原地編輯
換字、換圖、改圖表數據、複製/刪除/移動投影片、改背景
🏷️
套用範本
用公司品牌範本填值，自動套用母片字型與配色
🖼️
渲染驗證
把 pptx 轉成 PNG 圖片，逐頁確認視覺效果

💻 實際指令長這樣

# 從 JSON 規格建立簡報 python3 scripts/pptx_create.py deck.json out.pptx # 讀出全部內容／備忘稿 python3 scripts/pptx_read.py deck.pptx --outline python3 scripts/pptx_read.py deck.pptx --notes # 換文字、換圖片 python3 scripts/pptx_edit.py deck.pptx --replace-text "Old" "New" python3 scripts/pptx_edit.py deck.pptx --swap-image 2 logo.png # 複製／刪除／移動投影片 python3 scripts/pptx_edit.py deck.pptx --duplicate-slide 2 python3 scripts/pptx_edit.py deck.pptx --remove-slide 3 # 渲染成圖片確認 python3 scripts/pptx_render.py deck.pptx --outdir ./render

➗ 優缺點老實講

✅ 優點
• 離線、免裝 Office
• 自動化大量編輯
• 可套品牌範本
• 可渲染成圖驗證
• MIT 開源、安全
⚠️ 限制
• 只支援 .pptx（.ppt 要先轉檔）
• 圖表頁不能直接複製
• 需裝 python-pptx＋LibreOffice
• 視覺美感仍需人工把關

• 教育小孩：把知識做成生動投影片
