🐾 本次評估的 4 個技能

📂

google-workspace-ops

★★★★★ 238K★最推薦affaan-m
把 Google Drive / Docs / Sheets / Slides 當成「一個工作系統」來操作：找文件、摘要、原地精準編輯、整理試算表、匯入修復簡報、清理重複檔案。不是改單一檔案，而是整套雲端工作流。
🔒 安全性
純流程規範（SOP），無任何程式碼或惡意指令。✅
🎯 適合老大
⭐⭐⭐⭐⭐ 你重度用 Google Sheets 管財務＋整理資料，這技能能讓我更聰明地操控你的雲端文件、試算表、簡報。高度推薦。
📊

powerpoint

★★★★★ 227K★推薦NousResearch
用 python-pptx 建立/讀取/編輯 .pptx：從 JSON 規格建簡報、抽文字與備忘稿、換字換圖、複製刪除移動投影片、套公司範本、轉成 PNG 圖片。離線執行、免裝 Office。
🔒 安全性
MIT 開源、知名 AI 研究機構 NousResearch 出品，標準 python-pptx 操作指引，無惡意程式碼。✅
🎯 適合老大
⭐⭐⭐⭐ 工作簡報、退休規劃報告、未來教育小孩都可能用得到。需裝免費的 python-pptx。
🔬

consulting-analysis

★★★★ 79K★需要時用bytedance
產生「顧問級研究報告」（McKinsey / BCG 風格）：市場分析、競品分析、產業研究、投資盡職調查。含章節框架、圖表、策略洞察。極重視資料真實性、嚴禁幻覺杜撰，可輸出中文。
🔒 安全性
純方法論與流程規範，無程式碼、無惡意指令。✅
🎯 適合老大
⭐⭐⭐⭐ 若之後要寫投資標的評估、產業研究、公司簡報，這套很強。日常使用頻率較低。
✨

frontend-slides

★★★★ 238K★特定用途affaan-m
建立「動畫豐富的 HTML 投影片」，可從零做或把 PPT 轉成網頁簡報。零依賴、純瀏覽器跑，附設計樣式庫。輸出是網頁而非 .pptx。
🔒 安全性
純 CSS/JS 指引，無惡意指令。✅
🎯 適合老大
⭐⭐⭐ 想做出「很酷的網頁版簡報」時很好用；但要「可寄出的 .pptx」時，用 powerpoint 那個更實際。
